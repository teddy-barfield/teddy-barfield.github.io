Projects that look at New York State open data with an actuarial eye: what is measured, how it is normalized, and what the numbers can and cannot say.

How these projects are built

Each project pulls a public dataset from data.ny.gov, summarizes it with a reproducible Python script, and draws the charts from small processed data files. Every project page states the dataset, the agency that publishes it, a link and the date the data was pulled.

Write-ups stay analytical: they explain what a measure means, how it was normalized, and where it can mislead.
